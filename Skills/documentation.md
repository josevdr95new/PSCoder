# Skill: Documentation

## Description
Create, update, and improve documentation for code, projects, APIs, and systems.

## When to use
- User asks to create README, docs, or comments
- Need to document a codebase or project
- Writing API documentation or user guides
- Creating inline code comments
- Converting technical info into user-friendly docs

## Tools to use
- read_file - read existing code for understanding
- list_directory - explore project structure
- glob_files - find all source files
- write_file - create documentation files
- edit_file - update existing docs
- execute_powershell - extract info from code (function names, parameters)

## Workflow
1. Understand what needs to be documented
2. Read the source code or project files
3. Identify key components, functions, and structure
4. Write clear, organized documentation
5. Save as appropriate format (README.md, inline comments, API docs)
6. Verify the docs are complete and accurate

## Tips
- Use the project's existing documentation style
- Include code examples where helpful
- Write for the target audience (developers vs end users)
- Keep it up to date with the code
- Use markdown formatting consistently
- Include a table of contents for longer docs
- Document parameters, return values, and error cases
