Caracteristicas Principales

Todo lo que necesitas en un asistente de codigo impulsado por IA, directamente en tu terminal

🛠

19 Herramientas Integradas

Operaciones de archivos, ejecucion de comandos PowerShell, busqueda web, OCR, auto-curacion y mas. Cada herramienta esta disenada para interactuar con tu sistema de forma segura y eficiente.

⚡

8 Skills Especializados

Flujos de trabajo predefinidos para debugging, generacion de codigo, investigacion web, refactorizacion, administracion del sistema, extraccion de datos y documentacion.

🧠

Memoria Persistente

Memoria a largo plazo que persiste entre sesiones. PSCoder recuerda tus preferencias, proyectos y soluciones anteriores para ofrecerte respuestas mas contextuales.

🎓

Auto-Aprendizaje

Guarda automaticamente errores, soluciones y patrones para referencia futura. El sistema aprende de cada interaccion y mejora continuamente sus respuestas.

💉

Auto-Recuperacion

Diagnostica errores y sugiere soluciones con enfoques alternativos. Clasifica los errores por tipo y provee comandos de arreglo rapido y estrategias de recuperacion.

📁

Historial de Sesiones

Guarda, lista y carga conversaciones anteriores. Cada sesion captura mensajes, modelo, proveedor, tokens, costo y directorio de trabajo para continuity total.

8 Skills Especializados

Flujos de trabajo predefinidos que el agente carga automaticamente segun la tarea

Investigacion

Web Research

Busca, obtiene y sintetiza informacion actualizada de la web. Incluye verificacion de compatibilidad de versiones y busqueda con terminos alternativos.

Analisis

File Analysis

Analiza estructura de proyectos, codebases y configuraciones. Construye un mapa mental del proyecto leyendo puntos de entrada primero.

Debug

Debug Error

Diagnostica y resuelve errores con solucion sistematica en 9 pasos: verificar version, auto-heal, buscar soluciones, leer codigo, aplicar fix y verificar.

Generacion

Code Generation

Crea scripts, funciones y modulos nuevos desde cero. Respetando el estilo del proyecto, anadiendo manejo de errores y sin inventar APIs inexistentes.

Refactor

Refactor

Mejora calidad, legibilidad y rendimiento del codigo sin cambiar funcionalidad. Cambios pequenos y testeables, sin over-engineering.

Admin

PowerShell Admin

Tareas de administracion de sistemas Windows: servicios, procesos, registro, usuarios, redes y permisos. Recomienda -WhatIf para operaciones destructivas.

Datos

Data Extraction

Parsea y transforma datos de archivos, APIs y paginas web. Usa regex, ConvertFrom-Json/Xml, y manejo de codificacion para extraccion limpia.

Docs

Documentation

Crea y mejora documentacion de proyectos. Incluye ejemplos de codigo, documentacion de parametros y valores de retorno.

Inicio Rapido

Comienza a usar PSCoder en 3 simples pasos

1

Clonar el repositorio

Copia el repositorio de GitHub a tu maquina local y navega al directorio del proyecto.

PowerShell
git clone https://github.com/josevdr95new/PSCoder.git
cd PSCoder
2

Configurar tu clave API

Necesitas una clave API de OpenRouter (recomendado) o Groq. Configurala como variable de entorno o interactivamente.

PowerShell - Opcion 1: Variable de entorno
$env:OPENROUTER_API_KEY = "tu-clave-aqui"
PowerShell - Opcion 2: Configuracion interactiva
Start-PSCoder
# Luego usa: /config apiKey tu-clave-aqui
3

Iniciar PSCoder

Ejecuta el asistente y comienza a interactuar con la IA. Tambien puedes usar el archivo .bat para Windows.

PowerShell
# Importar y ejecutar
Import-Module .\PSCoder.psd1
Start-PSCoder

# O directamente:
.\Start-PSCoder.ps1

# O con modelo especifico:
.\Start-PSCoder.ps1 -Model "openai/gpt-4o" -Provider "openrouter"

Sistemas Inteligentes

Mecanismos avanzados que hacen a PSCoder autonomo y auto-mejorable

🧠

Memory Decision

Analiza cada turno de conversacion y decide automaticamente que informacion vale la pena persistir: errores resueltos, preferencias del usuario, contexto de proyecto, patrones de exito y flujos de comandos.

⚙

Reasoning Engine

Motor de planificacion que crea planes paso a paso con herramientas sugeridas y criterios de exito. Verifica cada paso individualmente y la tarea completa, con auto-curacion si un paso falla.

🔒

Sistema de Permisos

4 modos de permisos: Default (lecturas auto-aprobadas), AcceptEdits (auto-aprobar todo), BypassPermissions (sin aprobacion) y Plan (solo lecturas). Detecta comandos peligrosos como Remove-Item o Format-Volume.

🔔

Hooks

Sistema de hooks PreToolUse (puede bloquear ejecucion), PostToolUse (corre despues de ejecutar) y Stop (al final de cada turno). Scripts personalizables en ~/.pscoder/hooks/.

📊

Context Builder

Incluye automaticamente estado de Git (commits recientes, cambios sin commitear) y busca archivos PSCODER.md con instrucciones especificas del proyecto. Cache en memoria de 2 minutos.

🎤

Agent Narration

Retroalimentacion visual y por voz de las acciones del agente. Usa Windows SAPI para texto-a-voz, con colores diferenciados para pensamientos, acciones, resultados y errores.

Almacenamiento de Datos

    hooks/ — Scripts de hooks personalizados

Proveedores de IA

Compatible con multiples proveedores y modelos de lenguaje

🌐

OpenRouter (Recomendado)

Agregador que da acceso a GPT-4o, Gemini, Llama, Qwen, DeepSeek, Mistral y mas. Incluye modelos gratuitos y de pago. Cambio de modelo en caliente con /model.

⚡

Groq (Inferencia Rapida)

Inferencia ultrarapida para Llama, Mixtral, Gemma y Qwen. Ideal para respuestas rapidas. Soporta reasoning_effort y max_completion_tokens.

Cambio de modelo y proveedor
# Cambiar modelo
/model openai/gpt-4o
/model google/gemini-2.5-flash
/model qwen/qwen3.6-plus:free

# Cambiar proveedor
/provider openrouter
/provider groq
